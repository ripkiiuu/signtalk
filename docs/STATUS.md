## Dataset and model evidence

- Local WLASL metadata: `datasets/WLASL/start_kit/WLASL_v0.3.json`; 2,000 classes / 21,083 instances. Metadata includes signer IDs and official split labels. Signers overlap heavily between upstream splits; use the project's signer-hash split for experiments.
- WLASL license: C-UDA computational-use terms; source disclaims that it represents all upstream video rights. Do not use the upstream downloader until project/institutional authorization and rights are checked.
- ASL Signbank's official ECV metadata index (`datasets/ASLSignBank/asl.ecv`, 1,149,253 bytes / 4,528 gloss entries) was downloaded under CC BY-NC-SA 4.0 terms; it contains no videos/signer IDs.
- Candidate WLASL subset verified in the manifest: `who`, `drink`, `go`, `no`, `yes`, `help`, `what`, `before`; 199 manifest instances / 49 unique signer IDs, with 15–21 signer IDs per gloss. Metadata-only 60/20/20 grouping produced 30 train / 11 validation / 8 test signers with zero overlap; this is not video availability or training data.
- Safe subset plan reports 199 WLASL metadata entries, 0 local clips, 59 YouTube URLs and 140 other URLs not all rights-checked. Byte estimate is unknown. A HEAD-only size probe to 13 legacy ASL Signbank URLs failed with `URLError` for all; 0 video bytes downloaded. YouTube downloads are hard-skipped.
- ASL Citizen official archive is 45,924,134,223 bytes (~42.8 GiB); license is non-commercial, non-revenue research only, forbids redistribution, and requires consistency with participant consent. Full archive was not downloaded.
- ASL Citizen subset was extracted by HTTP byte ranges from Microsoft's official ZIP; 184 selected videos only (100,912,173 uncompressed bytes), not the 45,924,134,223-byte archive. Actual range transfer was 116,577,498 bytes. Local subset manifest includes participant IDs and must not be shared; source license prohibits redistribution and limits use to non-commercial/non-revenue research consistent with participant consent.
- Local model v2: `models/asl_citizen_6class_hand_logreg.joblib` and `.onnx` are ignored/private; v1 backups are kept locally. V2 fit on train+validation (112 clips / 29 signers), then tested on the untouched test split (72 clips / 11 signers): accuracy 0.8333, macro-F1 0.8347. Improvement over v1 was modest (+1.4/+1.0 percentage points); WHO test recall remained 13/14, with no WHO->NO errors in that small test. This does not ensure the model will recognize every live signer/angle or validate a particular user attempt.
- ONNX export parity: predicted labels match Python on 64 feature samples. The browser/WASM path was also exercised with a real held-out feature vector: browser predicted `who`, matching its source label, with 0.988 model output (not calibrated confidence). JavaScript temporal summary matches the Python feature builder to max absolute error <1e-6 on a deterministic fixture. This is a smoke test, not independent model validation.
- PWA camera practice allows explicit local selection of `models/asl_citizen_6class_hand_logreg.onnx`; no upload or persistent model storage. Supported targets get 32-frame progress and an experimental model-to-target comparison; unsupported targets such as `Hello` are deliberately not force-classified. Raw percentage output is hidden to avoid implying calibrated certainty. On mismatch, the UI says “model differs,” not that the learner is wrong; users can record their own source comparison (“matches example” / “needs guidance”). Coach guidance changes with hand visibility, model loading, sample coverage and model output; source steps can advance, analysis can restart, and Indonesian speech is optional. Procedural 3D hand art was removed. Where ASLU provides a hosted animated GIF/MP4, SIGNTALK streams it directly without player controls (WHO, GO, NO, YES, HELP, THANK YOU, BEFORE). Where only a YouTube embed is available, the PWA links to the publisher's player instead of placing player overlays over the practice screen. No media is downloaded or repackaged. Runtime WASM is excluded from precache but has cache-first runtime caching after download.
- Fixed a preview usability issue found during testing: muted camera video could remain paused after permission. The tracker now explicitly starts playback; synthetic-camera check confirms `video.paused === false`.
- Lesson details now use a wide responsive two-column layout with a lesson CTA, source/media panel, source-attributed step-by-step instruction, self-check questions and repeatable practice loop. The former narrow column/empty right side is fixed. ASL University source descriptions were checked for lesson-specific cues; SIGNTALK review remains pending.
- Active practice now puts the live camera in a sticky left column and prediction/coach in a right column on desktop; mobile stacks camera first. Verified at 1600/2000px (camera 736px wide at 2000) and 390px with no horizontal overflow. This keeps the learner's own signing visible alongside feedback. Progress copy shows `n/16` visible frames (not `32/16`); model UI no longer displays uncalibrated percentage scores.
- Python environment: `.venv` with MediaPipe 0.10.35, OpenCV contrib 4.11.0.86, scikit-learn 1.6.1 and ONNX Runtime 1.20.1. Extractor accepts both WLASL `samples` and ASL Citizen `video_samples`; timestamps are strictly increasing across the MediaPipe VIDEO task.
